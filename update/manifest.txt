# 快截（SnapCut）在线更新清单
#
# 这是纯文本清单（key=value），放在云端，程序通过 Settings.UpdateUrl 读取它。
# 只要这里的 version 比用户本机版本新，用户就会收到更新提示（由用户决定是否更新）。
#
# 发布新版本的步骤：
#   1. 本地构建：powershell -ExecutionPolicy Bypass -File .\build.ps1 -Bump
#   2. 把 build\SnapCut-Setup-vX.Y.Z.exe 上传到云端（如 GitHub Releases）
#      https://github.com/Lvbta/SnapCut/releases/new
#   3. 修改下面三行：version / url / notes，size 填安装包字节数（可选，用于显示体积）
#   4. 提交本文件；默认 UpdateUrl 指向
#      https://raw.githubusercontent.com/Lvbta/SnapCut/master/update/manifest.txt
#
# 字段说明：
#   version  三段版本号，如 1.2.1（比用户当前版本新才提示）
#   url      安装包下载地址（必须可直接下载）
#   notes    更新说明，会显示在更新窗口里（可用 \n 换行，也可多行写 notes2/notes3 合并）
#   size     安装包字节数，可选，用于显示"安装包 27.6 MB"

version=1.2.10

notes=fix: 启动时强制启用 TLS 1.2，修复 GitHub 更新包下载失败
